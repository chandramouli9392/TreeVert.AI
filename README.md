# 🌱 Overview

TreeVert AI is an intelligent AI + IoT system designed to understand the environmental condition and emotional state of trees using real-time sensor data.

By analyzing environmental parameters such as temperature, humidity, soil moisture, and light intensity, the system predicts how a tree is feeling and provides actionable insights for plant care and environmental monitoring.

---

# 🌟 Key Features

### 🌿 Tree Emotion Prediction

Predicts:

🟢 Happy

💧 Thirsty

🔥 Heat Stress

using Machine Learning.

---

### 📡 IoT Integration

Collects real-time data from:

* ESP32 Microcontroller
* DHT22 Sensor
* Soil Moisture Sensor
* LDR Light Sensor

---

### 🤖 AI-Powered Classification

Machine Learning model analyzes:

* Temperature
* Humidity
* Soil Moisture
* Light Intensity

and predicts the emotional condition of the tree.

# 📊 Dataset Features

The model is trained using environmental and biological indicators.

| Feature        | Description          |
| -------------- | -------------------- |
| 🌡 temp        | Temperature          |
| 💧 humidity    | Air Humidity         |
| 🌱 moisture    | Soil Moisture        |
| ☀️ light       | Light Intensity      |
| ⚡ mean_voltage | Simulated Bio Signal |
| 🧠 entropy     | Signal Complexity    |
| 🏷 label       | Tree Emotion         |
